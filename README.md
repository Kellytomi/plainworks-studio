# Plainworks Studio

A dependency-free static marketing website with privacy and terms pages.

- Live: https://plainworks-studio.vercel.app
- Build: `npm run build` (Node.js 20 or newer)
- Source: `public/`; generated output: `dist/`
- Hosting: Vercel, connected to `main`

Edit the HTML and CSS in `public/`, build locally, and push to `main` to publish updates.
